# VPSPanel v1.1.0

- **双栏加密 DNS。** 代理流量使用经健康上游的纯 IP DoH。直连流量和节点引导使用本机直发的 DoH，提供国内、海外两组预设。应用出口或备用域名变更时自动更新引导绑定。全部上游失效时拒绝代理解析，不回退明文，宿主机系统 DNS 保持独立。
- **Relay 1.5.0。** 托管模式下，直连健康检查及出口预检内置 DoH，按直连栏的顺序切换解析器。上游健康检查随各自链路执行。
- **默认自动分摊。** 新方案中，未命中显式规则的新连接从健康上游中分配。已有显式规则、已保存的默认动作和已建立的会话沿用原配置。
- **托管态备份。** 常规导出以当前托管 Xray 配置为底稿，恢复后保留有效的自定义入口与前置规则。未接管主机仍从原配置导出。导出托管底稿时请同时更新离线材料包。
- **旧包兼容。** 桌面端可继续打开并校验 v1.0.0（Relay 1.4.0）的 `.vpspack`。旧包恢复使用包内安装材料。

Windows x64 桌面包需要 .NET 10 桌面运行时。Linux x64 离线包包含 Xray 26.10.31、Relay 1.5.0 和 Geo 数据。下载后可用同一版本的 `SHA256SUMS.txt` 核对两个 ZIP。
